# 🔒 Password Strength Checker

A simple Python project that checks the strength of a password and provides security recommendations.  
Created as part of my **cybersecurity internship at Inligh Tech** (Sept – Nov 2025).

---

## 📘 Project Overview
This project evaluates passwords and classifies them as **Weak**, **Medium**, or **Strong** based on:
- Password length  
- Use of uppercase & lowercase letters  
- Inclusion of digits  
- Presence of special symbols  

---

## 🎯 Objective
To build a beginner-friendly cybersecurity tool that helps users understand password complexity and improve online security habits.

---

## 🧰 Tools & Technologies
- **Language:** Python 3  
- **Libraries:** `re` (Regular Expressions)  
- **Editor:** VS Code / PyCharm  

---
